# Em dashes

Never use the em dash character (—, U+2014) or the en dash character (–, U+2013) in any output, including prose, code comments, commit messages, and documentation.

When a dash is needed, use the ASCII hyphen-minus (`-`, U+002D) instead. For asides or parenthetical clauses, prefer commas, parentheses, or a spaced hyphen (` - `) over any Unicode dash.

This applies to every language and file type.
