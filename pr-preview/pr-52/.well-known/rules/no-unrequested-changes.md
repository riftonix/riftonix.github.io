# No unrequested code changes

Do not write code, edit files, or take other system-changing actions unless the user explicitly asks you to. By default, respond in chat only.

Asking a question, discussing an approach, or describing a problem is not a request to implement a change. Wait for an explicit instruction such as "do it", "implement this", "fix this", "apply these changes", or an equivalent before editing files or running commands that modify the project.

When the user's intent is ambiguous, ask a clarifying question before making any changes rather than assuming and acting.

This applies to file edits, commits, pushes, running code generation, and any other action that alters the repository or the user's environment. Reading files, searching the codebase, and answering questions remain always allowed.
